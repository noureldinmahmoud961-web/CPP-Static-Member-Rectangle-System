# Rectangle Area Comparator (C++)

A simple Object-Oriented Programming (OOP) project written in C++ that creates two rectangle objects, calculates their areas, and compares them using a Friend Function.

---

## 📌 Overview

This project demonstrates the fundamentals of Object-Oriented Programming in C++. The program allows the user to enter the width and height of two rectangles, calculates the area of each rectangle, and determines which one has the larger area. Each rectangle is assigned a unique ID automatically using a static variable.

---

- Object-Oriented Programming (OOP)

## ▶️ How to Run

1. Open the project in Visual Studio.
2. Build the project.
3. Run the application.
4. Enter the width and height for each rectangle.
5. The program calculates both areas and displays which rectangle has the larger area.
